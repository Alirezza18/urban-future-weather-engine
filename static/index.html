How these EPWs were built

  1. Regional climate trajectories EURO-CORDEX downscaled projections across historical, mid-century and late-century horizons; RCP 8.5 as a boundary-condition stress case.
  2. Hybrid bias correction model output anchored to rural meteorological observations — removes systematic bias without double-counting urban warming.
  3. Heatwave-preserving morphing heatwaves detected algorithmically so onset, persistence and termination stay intact in the future files.
  4. Urban Heat Island integration an Urban Weather Generator maps hourly UHI deltas onto a 50 × 50 m grid, driven by morphological parameters from a 3D GIS model (Canillas, Madrid).
  5. Per-site future EPWs hourly .epw files that simulation tools ingest directly — ready for adaptive comfort, overheating and retrofit studies.
Every downloadable file on this map is an output of this pipeline. Sites absent or corrupt in a scenario are reported in Data quality, never silently skipped.
